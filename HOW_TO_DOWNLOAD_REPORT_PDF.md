## 🔧 Troubleshooting

### **Issue: HTML file won't open**
**Solution:** Right-click → Open with → Choose your browser (Chrome, Edge, Firefox)

### **Issue: "Save as PDF" option not showing**
**Solution:** 
- In Chrome/Edge: Print dialog → Destination → "Save as PDF"
- In Firefox: Print dialog → Printer → "Microsoft Print to PDF"

### **Issue: Formatting looks wrong**
**Solution:** 
- Make sure "Background graphics" is enabled in print settings
- Use Chrome or Edge for best results
- Check that zoom is set to 100%

### **Issue: Code blocks are cut off**
**Solution:** 
- In print settings, try "Fit to page" or adjust scale to 90-95%
- Or use landscape orientation for wide code blocks
