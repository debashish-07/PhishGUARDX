```

  (Quantum × 0.15) +

  (Transformer × 0.25) +
```

```
1. URL Input

   ├─ Heuristics (25%)

   ├─ Visual DNA (10%)
   ├─ Transformer (25%)
   └─ ML Ensemble (25%)
   ↓
3. Weighted Aggregation
   ↓
4. Risk Score (0-100)
   ↓
5. Explainability Generation
   ↓
6. Visualization Rendering
   ↓
7. Results Display + PDF Option
```
